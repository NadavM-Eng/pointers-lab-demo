TeaVM in-browser Java compiler (teavm-javac), as published by the TeaVM playground
==================================================================================

These files are the in-browser Java compiler of https://github.com/konsoletyper/teavm-javac,
downloaded unchanged from https://teavm.org/playground/3/ on 2026-11-08 (the build that
https://teavm.org/playground.html loads). Three of them are stored gzip-compressed here; the two
class-library .bin files are already gzip streams and are stored as downloaded.

  compiler.wasm-deobfuscator.wasm.gz    compiler.wasm-deobfuscator.wasm   (gzip -9 -n)
  compile-classlib-teavm.bin            compile-classlib-teavm.bin        (as downloaded)
  runtime-classlib-teavm.bin            runtime-classlib-teavm.bin        (as downloaded)

Source
------
javac: teavm-javac builds it from the OpenJDK 25 updates repository at commit
6c48f4ed707bf0b15f9b6098de30db8aae6fa40f (gradle.properties, jdk.revision; the bundled javac
knows Java releases up to 25):
  https://github.com/openjdk/jdk25u/tree/6c48f4ed707bf0b15f9b6098de30db8aae6fa40f
teavm-javac (the build that produces compiler.wasm): https://github.com/konsoletyper/teavm-javac.
The playground build names no commit; every commit from 9dd58592331f44c14e6f81712a445918b3039faf
(2025-10-04, "Support Java 25") on uses the OpenJDK commit above.
TeaVM: https://github.com/konsoletyper/teavm.
